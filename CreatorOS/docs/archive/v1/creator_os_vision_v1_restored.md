## Original Vision

CreatorOS was a local-first, offline-first mobile content workspace for solo short-form creators. It unified idea capture, scripts, assets, search, repurposing, calendar, and publishing handoff around a single content record.

## Original MVP Scope

- Unified content record
- Idea capture
- Asset library and search
- Repurposing clip library
- Calendar/readiness
- Publishing handoff
- Integrations/storage
- Offline/sync

## Original Target User

Solo short-form creators across TikTok, Reels, and Shorts.

## Supersession Note

This v1 vision is superseded by `v2/creator_os_vision_v2.md`. The v2 pivot is to a connected content record for professional UGC creators.
