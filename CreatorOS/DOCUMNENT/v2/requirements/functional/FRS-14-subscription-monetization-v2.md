# Functional Requirements Specification — Module 14 v2: Subscription & Monetization

**Version:** 2.0
**Date:** 2026-08-23
**Supersedes:** v1 FRS-14 §4.3 pricing table

## 1. Purpose

This document defines v2 pricing and packaging. It replaces the v1 pricing table and limits.

## 2. v2 Plans

| Plan | Price | Limits |
|---|---:|---|
| Free | $0 | 1 workspace, 2 connected sources, 10 active connected records, basic search |
| Solo | $12/month annual / $15 monthly | Unlimited connected records, all initial connectors, connection health, action receipts |
| Pro | $20/month annual / $24 monthly | Higher sync frequency, advanced search, receipt export, multiple brands/workspaces |

## 3. Principles

- No per-channel or per-connector pricing.
- Free tier proves connected record value.
- User data export is never gated.

## 4. References

- Payment/restore mechanics: v1 FRS-14 remains valid except where pricing/limits conflict with this document.
