# UI/UX Documentation — CreatorOS v2

This directory contains the complete UI/UX documentation for CreatorOS Phase 2. These documents define the design principles, information architecture, screen inventory, user flows, and components needed for the mobile application.

## Document Index

1. [Design Principles](design-principles.md) - Core product design principles guiding every screen and interaction.
2. [Information Architecture](information-architecture.md) - Primary destinations, global utilities, content hierarchy, and navigation behavior.
3. [Screen Inventory](screen-inventory.md) - Comprehensive list of every screen and major component surface, including their purpose and states.
4. [User Flows](user-flows.md) - Primary user journeys from onboarding to complex error handling and reauthorization.
5. [Components](components.md) - Reusable UI components defined with semantic properties and states.
6. [Design Tokens](design-tokens.md) - Semantic and component tokens for color, typography, spacing, shape, elevation, and motion.
7. [State Matrix](state-matrix.md) - Matrix of global application, connection, and data states and how they manifest in the UI.
8. [Accessibility](accessibility.md) - Accessibility requirements targeting WCAG 2.2 AA and native platform standards.
